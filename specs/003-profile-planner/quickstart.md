# Quickstart: Profile and Session Planner

## Automated

```bash
npm test            # includes planner property tests (1,000 random profiles)
npm run test:rules
npm run build
```

## Manual (emulators)

1. Sign in as `invited@example.com`: setup starts. Pick 50–59, woman: goals suggest mobility,
   balance, bone strength. Finish.
2. Today: Calm morning, 15 min → Plan. Check the reasons, total time, gentle moves only; Swap one;
   Reshuffle; Start → player shows the same exercises.
3. Profile: set Yoga to None → new plans have no yoga. Set Knees to Avoid → no kneeling moves.
4. Desk break with batch 1 only: "not enough exercises yet" with a suggestion.
